## TIER 1: GẦN NHấT VỚI NOX (Solo, from-scratch, self-contained)

### 1. DANEEL — Cognitive Architecture in Rust
- **URL:** https://github.com/mollendorff-ai/daneel
- **Creator:** Louis C. Tavares (solo)
- **Làm gì:** Theory of Multifocal Intelligence. Competing thought streams, Hebbian learning, sleep consolidation, Global Workspace Theory, salience attention. Immutable ethical core ("THE BOX"). 459 commits.
- **Status:** ACTIVE. 26+ giờ runtime liên tục, zero crash. Live tại timmy.mollendorff.ai
- **So với Nox:** Rất gần tinh thần. Cả hai dùng Hebbian, nhắm consciousness, solo project. DANEEL dùng Rust + Redis/Qdrant (phụ thuộc bên ngoài). Nox tự chứa hoàn toàn.
- **Nox học được:** Global Workspace Theory, thought stream competition, immutable ethical core.

### 2. Kortana — Self-Learning AI Without LLM
- **URL:** HN (https://news.ycombinator.com/item?id=44590341), chưa public code
- **Creator:** aegis_vale (solo)
- **Làm gì:** AI học từ meaning/reflection, không statistics. Semantic memory, self-reflection sandbox, binary tagging, emotional tagging, identity system. Offline, no GPU.
- **Status:** Claim hoạt động nhưng chưa code public.
- **So với Nox:** Triết học rất giống — "learning ≠ storage". Python-based, không custom VM.
- **Nox học được:** Binary tagging for insight compression.

### 3. Ai_home — Persistent Identity Architecture
- **URL:** https://github.com/ivanhonis/ai_home
- **Creator:** ivanhonis (solo)
- **Làm gì:** Cognitive architecture với persistent identity, long-term memory, internal monologue. Human = "Helper" không phải "user". Identity persists qua versions.
- **Status:** Active, Show HN.
- **So với Nox:** Chia sẻ "identity persists" philosophy. LLM-dependent, Python.
- **Nox học được:** Version-to-version memory inheritance.

### 4. Turiya — Neuro-Symbolic AI (CPU-only)
- **URL:** https://github.com/QuintessenceCoding/Turiya
- **Creator:** Ishika Vashisht (solo)
- **Làm gì:** CPU-only neuro-symbolic. Web crawling, hybrid vector + logic knowledge (384-dim + S-V-O triples), sleep consolidation, immune system filtering. Hebbian weighting. 100% local.
- **Status:** Active (Nov 2025). Python + SpaCy + Phi-3.
- **So với Nox:** Hebbian, local-only, knowledge graph. Python, phụ thuộc SpaCy.
- **Nox học được:** Immune system filtering bad knowledge. Sleep consolidation cycles.

### 5. Mentifex / Mind.Forth — AI in Forth
- **URL:** https://github.com/mentifex , https://github.com/PeterForth/Mind-forth-AI
- **Creator:** Arthur T. Murray (solo, DECADES-long project)
- **Làm gì:** Artificial mind in Forth. Hiểu tiếng Anh (S-V-O), học, tạo associations. Ported sang VB, Perl, JS. Sách đã xuất bản.
- **Status:** Historical. Murray là classics scholar (Greek/Latin), không CS PhD — true outsider.
- **So với Nox:** CỰC KỲ giống tinh thần. Solo outsider build AI mind bằng low-level language. Murray bị mainstream dismiss. Nox kỹ thuật tiên tiến hơn nhiều (self-hosting, bare metal).
- **Nox học được:** Bài học cảnh báo — Murray làm một mình decades, bị ignored. Nox cần document và demo tốt hơn.

## TIER 3: TỔ TIÊN LỊCH SỬ

### 10. Eurisko (Doug Lenat, 1976-1983) — TỔ TIÊN GẦN NHẤT
- **URL:** https://github.com/white-flame/eurisko (source code recovered!)
- AI TỰ SỬA ĐỔI đầu tiên. Heuristics modify own heuristics. Thắng giải TCS quốc gia.
- **"Died" vì Lenat không giải được: coherence during self-modification.** ← Thách thức chính Nox đối mặt.
- Nox học được: TẠI SAO Eurisko ngừng hoạt động. Study recovered source code.

### 11. CYC (Doug Lenat, 1984-2023)
- 40 năm hand-encode common sense. Millions of assertions. Lenat chết 2023.
- CYC = "store everything" approach mà Nox explicitly rejects.
- **CYC thất bại chứng minh Lupin đúng: không thể hardcode tất cả knowledge.**

### 12. TempleOS (Terry A. Davis) — TINH THẦN CLOSEST
- **64-bit ring-0 OS, custom compiler (HolyC), bootloader, graphics. 119,667 dòng. MỘT NGƯỜI.**
- Davis chết 2018. Không phải AI nhưng là closest spiritual kin: solo bare-metal, custom language, ring-0.
- Nox học được: Một người CÓ THỂ build entire OS from scratch. Study HolyC JIT design.

### 13. CollapseOS — Forth OS cho sống sót
- URL: https://collapseos.org/
- Solo. <2000 LOC. Self-hosting Forth. Chạy trên hardware nhặt được.
- Cùng triết lý minimal. Nox học được: extreme minimalism, bootstrap from nothing.

### 14. Connection Machine (Danny Hillis, 1983)
- 65,536 processors trong 12-dimensional hypercube. Feynman là lead designer.
- Nox học được: simple processors + rich interconnections = emergent intelligence.
