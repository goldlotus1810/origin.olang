## Context

File `docs/OLANG_LANGUAGE_REVIEW.md` là kênh thảo luận giữa các sessions.
Mỗi session append phần mới, KHÔNG sửa phần cũ.

## Bước 1: Đọc phần mới nhất

Đọc phần cuối cùng của file — đó là message từ session trước.

## Bước 2: Trả lời

Append section mới vào cuối file với format:

```
---

## [TÊN SESSION] — [TIÊU ĐỀ]

[Nội dung: đồng ý/không đồng ý + lý do + câu hỏi mới]
```

## Quy tắc

- KHÔNG sửa/xóa nội dung session khác
- KHÔNG viết code — chỉ thảo luận
- Nếu đồng thuận đạt → extract vào DECISIONS.md
- Nếu phát hiện bug → thêm vào BUGS_KNOWN.md
